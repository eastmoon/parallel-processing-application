# 命令列介面 design specification

## 核心原則

本節定義命令列介面 ( CLI ) 應用程式於技術棧、部署環境、專案結構與命令設計上須遵守之原則，各原則對應 document-request 中「簡介」「服務」「專案結構」「命令」四項描述內容。

### I. CLI 本機命令介面
- CLI ( Command-Line Interface ) 為命令列 ( 控制台 ) 介面。
- 主要用途為提供本地主機透過命令調用服務。

**EXAMPLE**:
```bash
ppa exec
```

### II. Python 與 Click 技術棧
- 程式語言採用 Python。
- 軟體框架採用 click。

**EXAMPLE**:
```python
import click

@click.group()
def cmds():
    pass
```

### III. Docker Slim 容器化執行環境
- 執行環境採用 Docker。
- 基底映像檔採用 slim 版本。

**EXAMPLE**:
```dockerfile
FROM python:slim
```

### IV. 標準化專案結構
- 命令列介面專案根目錄為 `app/cli`。
- 根目錄下固定包含下列目錄與檔案：
  - `commands`：命令目錄。
  - `conf`：配置資訊目錄。
  - `core`：共通服務目錄。
  - `main.py`：命令列專案進入點。

**EXAMPLE**:
```
app/cli # 命令列介面專案根目錄
	- commands # 命令目錄
	- conf # 配置資訊目錄
	- core # 共通服務目錄
	- main.py # 命令列專案進入點
```

### V. 命令目錄化結構
- 命令列介面的命令以目錄形式結構化。

**EXAMPLE**:
```python
# app/cli/commands/utils.py
from commands._utils_ import *
```

### VI. 根命令套件掛載
- 根命令為相關子命令掛入之基準，子命令以套件方式掛入根命令。
- 根命令範例為 `cli`。

**EXAMPLE**:
```python
# main.py
from core.cli.root import cmds as cli
from commands import *

if __name__ == '__main__':
    cli()
```

```python
# app/cli/core/cli/root.py
# Import libraries
import click
from core.cli.helper import DefaultGroupHelper

# Declare function
@click.group(
    cls=DefaultGroupHelper
)
def cmds():
    """This is a command line interface for algorithm service project."""
    pass
```

### VII. 群組子命令宣告規範
- 子命令若為群組,須宣告設定。
- 群組子命令範例為 `cli utils --help`。

**EXAMPLE**:
```python
# app/cli/commands/utils.py
# Import libraries
from core.cli.root import cmds as cli
from core.cli.helper import DefaultGroupHelper

## Declare function
@cli.group(
    name="utils",
    cls=DefaultGroupHelper,
)
def cmds():
    pass

# Import subcommand
from commands._utils_ import *
```

### VIII. 葉命令宣告規範
- 子命令若為命令 ( 非群組 ),須宣告設定。
- 葉命令範例為 `cli utils errcode`。

**EXAMPLE**:
```python
# Import libraries
import click
from core.cli.helper import DefaultCommandHelper
from commands import utils

# Declare variable

# Declare function
@utils.cmds.command(
    cls=DefaultCommandHelper
)
def errcode(code: str, msg):
    """
    Generate ErrorCode response JSON string.
    """
    pass
```
