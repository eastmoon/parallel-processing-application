# Inter-process communication technology specification

## 通訊機制技術規範

本規範定義行程間通訊 (Inter-process communication) 所採用之技術堆疊與各通訊機制之實作要求。

### I. 共享記憶體 (Shared Memory)

+ 須以 Python `multiprocessing.shared_memory` 模組實作。
+ 發送端須以 `create=True` 建立具名記憶體區塊並指定 `size`；接收端須以相同 `name` 連接至既有區塊。
+ 發送、接收雙方須各自呼叫 `close()`；建立端須於使用完畢後另行呼叫 `unlink()`。

**Rationale**: 共享記憶體機制須考量發送、接收訊息之機制，故明定建立、連接、釋放三項操作之呼叫責任歸屬。

**EXAMPLE**:
```python
from multiprocessing import shared_memory

def send(name: str, data: bytes) -> None:
    shm = shared_memory.SharedMemory(create=True, size=len(data), name=name)
    shm.buf[:len(data)] = data
    shm.close()

def receive(name: str, size: int) -> bytes:
    shm = shared_memory.SharedMemory(name=name)
    data = bytes(shm.buf[:size])
    shm.close()
    shm.unlink()
    return data
```

### II. 管道 (Pipes)

+ 須以 Python `multiprocessing.Pipe` 模組實作。
+ `Pipe()` 須產生一對 `Connection` 物件；任一端皆可呼叫 `send()` 傳送資料或 `recv()` 接收資料。

**Rationale**: 管道機制須考量發送、接收訊息之機制，故明定 `send`/`recv` 為雙端共用之操作介面。

**EXAMPLE**:
```python
from multiprocessing import Pipe, Process

def sender(conn) -> None:
    conn.send(b"hello")
    conn.close()

if __name__ == "__main__":
    parent_conn, child_conn = Pipe()
    p = Process(target=sender, args=(child_conn,))
    p.start()
    data = parent_conn.recv()
    parent_conn.close()
    p.join()
```

### III. Socket（本機網路）

+ 須以 Python `socket` 模組實作，位址族別為 `AF_INET`。
+ 接收端須綁定 `0.0.0.0`，以監聽本機所有網路介面之連線請求；發送端須連線至目標位址後傳送資料。

**Rationale**: Socket 機制須考量發送、接收訊息之機制，並須設置於本機網路，故明定綁定位址為 `0.0.0.0`。

**EXAMPLE**:
```python
import socket

def receive(bind_address: tuple = ("0.0.0.0", 9000)) -> bytes:
    server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server.bind(bind_address)
    server.listen(1)
    conn, _ = server.accept()
    data = conn.recv(4096)
    conn.close()
    return data

def send(address: tuple, data: bytes) -> None:
    client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    client.connect(address)
    client.sendall(data)
    client.close()
```
