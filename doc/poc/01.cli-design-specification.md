## 核心原則

本節定義命令列介面 ( CLI ) 於技術棧、專案結構與命令宣告上須遵守之原則。原則 I 對應調研描述「簡介」；原則 II 對應輸入之程式語言與軟體框架，以及「命令」範例中之 `core.cli.helper` 模組；原則 III 對應「專案結構」；原則 IV 至 VII 對應「命令」。

- 範例驗證方式：邏輯檢查 ( 未建置映像檔、未執行程式 )。
- 環境版本：輸入未指定 Python 與 click 之版本。
- 標記說明：
  - 「範例補充」：調研描述未提供，為使範例於邏輯檢查中完整運作而補足之檔案或程式行。
  - 「根據文本推測」：依調研描述原文推論之結論，附原文依據。
  - 「邏輯檢查」：範例程式邏輯檢查之結果。

### I. CLI 本機命令介面

- CLI ( Command-Line Interface ) 為命令列 ( 控制台 ) 介面。
- 主要用途為提供本地主機透過命令調用服務，例如 `ppa exec`。
- 命令列專案進入點為 `main.py`。
- 調研描述未定義 `ppa` 與根命令 `cli` 之對應方式，亦未定義 `exec` 命令之內容。
- 邏輯檢查：`main.py` 以 `__name__ == '__main__'` 條件呼叫根命令 `cli()`，由 click 解析命令列參數並分派至對應之子命令。

**EXAMPLE**:

`app/cli/main.py`

```python
# main.py
from core.cli.root import cmds as cli
from commands import *

if __name__ == '__main__':
    cli()
```

### II. Python 與 click 技術棧

- 程式語言採用 Python。
- 軟體框架採用 click。
- 根命令與群組子命令之宣告設定為 `cls=DefaultGroupHelper`，命令之宣告設定為 `cls=DefaultCommandHelper`，兩者由 `core.cli.helper` 模組提供。
- 根據文本推測:`core.cli.helper` 模組檔案位於 `app/cli/core/cli/helper.py`(依據:『# app/cli/core/cli/root.py』、『from core.cli.helper import DefaultGroupHelper』)。
- 根據文本推測:`DefaultGroupHelper` 須提供 `group` 與 `command` 宣告方法(依據:『cls=DefaultGroupHelper』、『@cli.group(』、『@utils.cmds.command(』)。
- 調研描述未定義 `DefaultGroupHelper` 與 `DefaultCommandHelper` 之客製內容。
- 邏輯檢查：click 以 `cls` 參數指定建立群組或命令所使用之類別；範例中 `DefaultGroupHelper` 繼承 `click.Group`，`DefaultCommandHelper` 繼承 `click.Command`，未加入客製內容。

**EXAMPLE**:

`app/cli/core/cli/helper.py` ( 範例補充 )

```python
# app/cli/core/cli/helper.py
# Import libraries
import click

# Declare class
class DefaultGroupHelper(click.Group):
    pass

class DefaultCommandHelper(click.Command):
    pass
```

### III. 標準化專案結構

- 命令列介面專案根目錄為 `app/cli`。
- 根目錄下包含下列目錄與檔案：
  - `commands`：命令目錄。
  - `conf`：配置資訊目錄。
  - `core`：共通服務目錄。
  - `main.py`：命令列專案進入點。
- 根據文本推測:模組匯入路徑以 `app/cli` 為根(依據:『# app/cli/core/cli/root.py』、『from core.cli.root import cmds as cli』)。
- 調研描述未定義 `conf` 目錄之內容。

**EXAMPLE**:

專案結構 ( 取自調研描述 )

```
app/cli # 命令列介面專案根目錄
	- commands # 命令目錄
	- conf # 配置資訊目錄
	- core # 共通服務目錄
	- main.py # 命令列專案進入點
```

`main.py` 匯入敘述與檔案位置之對應

```python
from core.cli.root import cmds as cli   # app/cli/core/cli/root.py
from commands import *                  # app/cli/commands/__init__.py
```

### IV. 命令目錄化結構

- 命令列介面的命令採用每個命令以目錄形式結構化。
- 根據文本推測:群組 `utils` 宣告於 `commands/utils.py`，其子命令置於 `commands/_utils_` 套件目錄(依據:『# app/cli/commands/utils.py』、『# Import subcommand』、『from commands._utils_ import *』)。
- 根據文本推測:命令 `errcode` 隸屬群組 `utils`(依據:『@utils.cmds.command(』、『cli utils errcode』)。
- 子命令目錄名稱 `_utils_` 於調研描述中僅有單一範例，調研描述未定義通用命名規則。

**EXAMPLE**:

範例專案結構 ( 標示 `*` 者為範例補充；`errcode.py` 之程式內容取自調研描述，檔案位置為範例補充 )

```
app/cli
	- commands
		- __init__.py *
		- utils.py
		- _utils_
			- __init__.py *
			- errcode.py *
	- conf
	- core
		- __init__.py *
		- cli
			- __init__.py *
			- helper.py *
			- root.py
	- main.py
```

命令與宣告檔案之對應 ( 路徑相對於 `app/cli` )

| 命令 | 宣告檔案 | 宣告設定 |
| --- | --- | --- |
| `cli` | `core/cli/root.py` | `@click.group(cls=DefaultGroupHelper)` |
| `cli utils` | `commands/utils.py` | `@cli.group(name="utils", cls=DefaultGroupHelper)` |
| `cli utils errcode` | `commands/_utils_/errcode.py` | `@utils.cmds.command(cls=DefaultCommandHelper)` |

### V. 根命令套件掛載

- 根命令例如 `cli`，相關子命令以套件方式掛入。
- 根命令宣告於 `app/cli/core/cli/root.py`：函式 `cmds` 以 `@click.group(cls=DefaultGroupHelper)` 宣告，docstring 為 `This is a command line interface for algorithm service project.`。
- `main.py` 以 `from core.cli.root import cmds as cli` 取得根命令，以 `from commands import *` 掛入子命令，並於 `if __name__ == '__main__':` 區塊呼叫 `cli()`。
- 邏輯檢查：`from commands import *` 載入 `commands/__init__.py` 之 `__all__` 所列子模組；未定義 `__all__` 時，`commands/utils.py` 不被載入，群組 `utils` 不掛入根命令。範例以 `__all__ = ["utils"]` 列出子命令模組。

**EXAMPLE**:

`app/cli/main.py`

```python
# main.py
from core.cli.root import cmds as cli
from commands import *

if __name__ == '__main__':
    cli()
```

`app/cli/core/cli/root.py`

```python
# app/cli/core/cli/root.py
# Import libraries
import click
from core.cli.helper import DefaultGroupHelper

# Declare function
@click.group(
    cls=DefaultGroupHelper
)
def cmds():
    """This is a command line interface for algorithm service project."""
    pass
```

`app/cli/commands/__init__.py` ( 範例補充 )

```python
# app/cli/commands/__init__.py
# Declare variable
__all__ = ["utils"]
```

### VI. 群組子命令宣告規範

- 子命令若為群組，需宣告設定，例如 `cli utils --help`。
- 群組宣告檔為 `app/cli/commands/utils.py`：以 `from core.cli.root import cmds as cli` 取得上層群組，以 `@cli.group(name="utils", cls=DefaultGroupHelper)` 宣告函式 `cmds`。
- 群組之子命令於檔案末端以 `from commands._utils_ import *` 匯入。
- 根據文本推測:群組之命令名稱由 `name` 參數指定，群組函式名稱為 `cmds` 以供子命令參照(依據:『name="utils",』、『def cmds():』、『@utils.cmds.command(』)。
- 根據文本推測:子命令匯入須位於群組宣告之後(依據:『# Import subcommand』、『from commands._utils_ import *』、『@utils.cmds.command(』)。子命令模組於 `commands/utils.py` 執行至末端匯入敘述時載入，並於載入時參照 `utils.cmds`，`cmds` 須於該匯入敘述執行前完成宣告。
- 邏輯檢查：`from commands._utils_ import *` 載入 `commands/_utils_/__init__.py` 之 `__all__` 所列子模組；範例以 `__all__ = ["errcode"]` 列出命令模組。

**EXAMPLE**:

`app/cli/commands/utils.py`

```python
# app/cli/commands/utils.py
# Import libraries
from core.cli.root import cmds as cli
from core.cli.helper import DefaultGroupHelper

## Declare function
@cli.group(
    name="utils",
    cls=DefaultGroupHelper,
)
def cmds():
    pass

# Import subcommand
from commands._utils_ import *
```

`app/cli/commands/_utils_/__init__.py` ( 範例補充 )

```python
# app/cli/commands/_utils_/__init__.py
# Declare variable
__all__ = ["errcode"]
```

### VII. 葉命令宣告規範

- 子命令若為命令 ( 非群組 )，需宣告設定，例如 `cli utils errcode`。
- 命令模組以 `from commands import utils` 取得所屬群組模組，以 `@utils.cmds.command(cls=DefaultCommandHelper)` 宣告命令函式。
- 範例命令函式為 `errcode(code: str, msg)`，docstring 為 `Generate ErrorCode response JSON string.`。
- 根據文本推測:命令名稱取自函式名稱(依據:『def errcode(code: str, msg):』、『cli utils errcode』)。
- 根據文本推測:命令模組位於 `commands/_utils_` 目錄(依據:『from commands._utils_ import *』)。
- 邏輯檢查：click 僅以已宣告之參數 ( `click.argument`、`click.option` ) 傳值予命令函式；調研描述之 `errcode` 未宣告 click 參數，執行 `cli utils errcode` 時命令函式缺少 `code`、`msg` 引數。範例以 `@click.argument` 對應兩個必要位置參數。
- 調研描述未定義 `errcode` 產生 ErrorCode JSON 字串之內容，範例函式本體維持 `pass`。

**EXAMPLE**:

`app/cli/commands/_utils_/errcode.py` ( 檔案位置與 `click.argument` 宣告為範例補充 )

```python
# app/cli/commands/_utils_/errcode.py
# Import libraries
import click
from core.cli.helper import DefaultCommandHelper
from commands import utils

# Declare variable

# Declare function
@utils.cmds.command(
    cls=DefaultCommandHelper
)
@click.argument("code")
@click.argument("msg")
def errcode(code: str, msg):
    """
    Generate ErrorCode response JSON string.
    """
    pass
```
